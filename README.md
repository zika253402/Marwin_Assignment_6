## Important design note
This project continues Assignment 5. The original `index.html` structure, `style.css`, colors, typography, hero illustration, product cards, theme switch, favorites, ratings, modal, FAQ and other existing interactions were kept. Assignment 6 adds jQuery features on top of the existing design.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or open the folder in VS Code and use Live Server.
3. Internet is required for jQuery CDN and remote product photos. If remote photos fail, the original product emoji and colored backgrounds remain as a fallback.
4. Open Developer Tools → Console and check for `jQuery is ready!`.

## Assignment 6 tasks
- Task 0: jQuery CDN, `$(document).ready()`, and console test.
- Task 1: real-time product search and live category filter.
- Task 2: autocomplete search suggestions.
- Task 3: matching words highlighted in product titles and descriptions.
- Task 4: colorful scroll progress bar.
- Task 5: animated number counters.
- Task 6: spinner, `Please wait…`, and temporarily disabled submit button.
- Task 7: temporary toast notifications with jQuery fade effects.
- Task 8: copy-to-clipboard button with checkmark feedback.
- Task 9: lazy loading of product photos.

## Existing Assignment 5 features retained
Category buttons, bag counter, favorites, product ratings, night/day theme switch, Surprise Me interaction and sound, Read More, signup validation and clear form, FAQ accordion, subscription modal, keyboard navigation, and responsive layout.

Deploy the project folder using GitHub Pages or Netlify. Add the real published URL to the report after deployment.
